File System Management

Discover how files and folders are organized, named, secured, and detailed with metadata to maintain order and security within an operating system.

Hierarchy & Organization

  • Files vs. Folders: Files hold raw data; folders (directories) organize files.
  • Hierarchical Structure: Data is organized in a branching, tree-like structure stemming from a single base.
  • Root Directory: The topmost directory (e.g., `C:\` in Windows, `/` in Linux).

File Permissions

  • Purpose: Regulates exactly who can read, modify, or run specific files.
  • Windows (NTFS): Uses explicit rules like Read, Write, Modify, and Full Control.
  • Linux/macOS (Unix): Uses a compact `rwx` (read, write, execute) model for Owner, Group, and Others.

Naming Restrictions

  • Forbidden Characters: Prevents system confusion (e.g., Windows bans `\/:*?"<>|`).
  • Reserved Names: System keywords that cannot be used (e.g., `CON`, `PRN`).
  • Case Sensitivity: Windows treats `File.txt` and `file.txt` equally; Linux sees them as distinct.

Metadata & Attributes

  • Metadata: Contextual "data about data" (dates, owner, size).
  • Properties: Informational details to help the user manage files (File size, Date created).
  • Attributes: System instructions dictating how a file is handled (Hidden, Immutable, Read-only).
