            Terminal Diagnostics Commands
            

              
• ipconfig /all : Win7 IP, MAC, Subnet & Gateway

              
• ifconfig : Ubuntu Linux network configuration

              
• nslookup : Queries DNS for IP of a domain

              
• netstat -an : Windows active listening ports

              
• ss -tuln : Modern Ubuntu active TCP/UDP ports

              
• ping 127.0.0.1 : Local device loopback test

              
• tracert (Win) / traceroute (Linux) : Hop count & path

              
• ping -c 4 : Ubuntu 4-packet ICMP test

            

          


          
          

            Essential Network Ports
            

              
• 21: FTP (Files)

              
• 22: SSH (Secure Shell)

              
• 23: Telnet (Insecure)

              
• 25: SMTP (Old email)

              
• 53: DNS (Name lookup)

              
• 80: HTTP (Web)

              
• 110: POP3 (Mail download)

              
• 143: IMAP (Mail sync)

              
• 443: HTTPS (Secure Web)

              
• 587: SMTP (Secure email)

              
• 631: CUPS (Unix Print)

              
• 3389: RDP (Remote Desktop)

            

          


          
          

            Devices & Addressing Concepts
            
    
              
  • MAC Address: 48-bit physical hex address permanently baked into NIC. Used by switches.
    • 
              
  • IP Address: Logical address (IPv4 32-bit, IPv6 128-bit hex). Separated into network vs host by Subnet Mask.
    • 
              
  • Router & NAT: Connects LAN to WAN. Network Address Translation translates private IPs to one public IP.
    • 
              
  • TCP vs UDP: TCP is reliable/guaranteed (certified mail). UDP is fast/connectionless (tossing flyers).
    • 
              
  • DHCP: Dynamically hands out IP addresses using ports 67 (server) & 68 (client).
    • 
              
  • ICMP: Protocol used by ping. Frequently blocked by Windows Firewall by default.
    • 
            

          


          
          

            Wireless Bands & Performance (2.9.1)
            

              

                2.4 GHz
                
Longest range, best wall penetration, slowest speed, highest interference (microwaves, bluetooth, smart plugs).

              

              

                5 GHz
                
Medium range, fast speed, lower interference, struggles more with solid walls.

              

              

                6 GHz
                
Shortest range, ultra-fast speeds, widest channels, cannot easily penetrate walls, cleanest spectrum.

              

            

            

              • Attenuation: Signal loss over distance/walls. • Latency: Millisecond delay before data travels (low is best). • TWT (Target Wake Time): Wi-Fi 6 power-saving scheduling.
