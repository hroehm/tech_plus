Install & Configure Peripherals

Learn how to properly connect, install, and configure the external hardware devices that bring computers to life. Review this briefing before moving to the Lab Activity.

Peripheral Devices

  • Definition: External devices that connect to a computer to add features, improve performance, or provide I/O options.
  • Input: Keyboards, mice, web cameras, scanners. Send data *to* the system.
  • Output: Printers, displays, speakers. Receive data *from* the system.
  • Power/Storage: UPS (Uninterruptible Power Supply) and external hard drives.

Installation Types

  • Installation: The process of setting up software or hardware so it can begin working on a system.
  • Plug-and-Play (PnP): Devices automatically recognized and configured by the OS. No manual driver install needed.
  • Driver Installation: Required for hardware not automatically recognized. A driver acts as a software translator between the OS and the device.

Configuration & Testing

  • Configuration: Adjusting settings *after* installation to ensure the device operates exactly as the user wants.
  • Testing: The critical final step (e.g., printing a test page, checking a video feed, calibrating a scanner).
  • Firmware: Checking for updates to the hardware's internal permanent software for stability and security.

IP-Based Peripherals

  • Definition: Peripherals that connect to a user's network rather than directly to a single computer.
  • Addressing: Handled dynamically via DHCP or manually via a Static IP address.
  • Web-Based Configuration: Managing the peripheral's settings by typing its IP address into a standard web browser (like Firefox/Chrome).
