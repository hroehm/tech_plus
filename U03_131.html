Storage Units & Data Measurement

Explore how computing devices store data from binary bits to petabyte cloud infrastructures, and how scale units dictate modern digital design.

Bits & Bytes (Micro Level)

  • Bit (b): Smallest data unit representing binary 0 or 1.
  • Byte (B): Group of 8 bits; encodes a single alphanumeric character.
  • Review Summary: Forms the basic transistor and voltage foundation for hardware signal pathways and text representation.

Kilobytes & Megabytes

  • Kilobyte (KB): 1,024 bytes; text emails and documents.
  • Megabyte (MB): 1,024 KB; smartphone photos and PDF files.
  • Review Summary: Intermediate productivity units bridging raw binary code with human-readable files.

Gigabytes & Terabytes

  • Gigabyte (GB): 1,024 MB; standard metric for movies and apps.
  • Terabyte (TB): 1,024 GB; modern PC & console storage.
  • Review Summary: High-capacity metrics essential for multimedia storage, large gaming libraries, and virtual memory swap files.

Petabytes & Cloud Scale

  • Petabyte (PB): 1,024 terabytes; used by major tax agencies and cloud hubs.
  • Exabytes (EB): Global streaming & data totals.
  • Review Summary: Institutional scale repositories requiring distributed RAID networks and redundant data-center mirroring.
