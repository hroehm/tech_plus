Network Storage Devices

Explore how data is stored, shared, and accessed across local networks and the internet. Review this briefing thoroughly before proceeding to the Lab Activity.

Local vs. Network Storage

  • Local Storage: Hard drives (HDDs) or Solid-State Drives (SSDs) directly connected to a single device.
  • Isolation: Data on local storage can only be accessed by that specific device.
  • Network Storage: Storage connected to a Local Area Network (LAN). Data is accessible to multiple authorized users across different computers.

Network-Attached Storage

  • NAS Definition: A dedicated appliance providing file-based data storage services to the network.
  • Redundancy: Often utilizes RAID (Redundant Array of Independent Disks) to protect against data loss if one drive fails.
  • Connectivity: Connects directly to the network switch or router via an Ethernet cable.

File Servers

  • Definition: A powerful, dedicated computer managing complex file storage, backups, and access permissions.
  • Protocols: Uses SMB (Server Message Block) for Windows environments and NFS (Network File System) for Linux/Unix.
  • Scalability: Highly configurable, but creates a single point of failure if the server goes offline.

Cloud & Remote Access

  • Cloud Storage: Data kept on remote servers, accessible anywhere via the internet. Eliminates local hardware maintenance.
  • CLI Tools: `wget` (Linux) and `curl` (Windows/Linux) are used to download files from web servers (like Apache2).
  • SSH: Secure Shell. Provides encrypted remote terminal access to manage servers and files securely.
