Hexadecimal & Decimal

Explore the bridge between binary data and human readability. Learn how the base-16 numeral system powers memory addressing, network identification, and error logging.

Intro to Hexadecimal

  • Base-16 System: Utilizes 16 distinct symbols to represent values.
  • Alphanumeric: Uses digits 0-9 and letters A-F to account for all 16 values.
  • Binary Shorthand: Every hex digit represents exactly 4 bits (a nibble) of binary data.

Hex to Decimal

  • Place Values: Based on powers of 16 (16^0, 16^1, 16^2).
  • Pre-Conversion: Letters A-F must be translated to 10-15 before calculating.
  • Multiplication: Digits are multiplied by their respective place values and summed.

Decimal to Hex

  • Division Method: Repeatedly divide the decimal number by 16.
  • Tracking Remainders: The remainders of each division form the hex digits.
  • Bottom to Top: Remainders are read from the last calculation up to the first.

IT Applications

  • MAC Addresses: Identifies network hardware manufacturers via OUIs.
  • Color Codes: Defines precise RGB combinations in web design.
  • System Diagnostics: Utilized in error codes (0x) and memory addressing.
