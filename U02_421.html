Fundamental Data Types

Understanding the built-in building blocks of programming languages and how to categorize, manipulate, and convert data effectively.

Characters & Strings

  • Char: A single glyph, letter, digit, or symbol (e.g., 'A', '$', '7').
  • String: A sequence of characters containing letters, numbers, or symbols (e.g., "Bread", "123 Main St").
  • Indexing: Using numbers to locate a specific character's position within a string.

Numbers (Int, Float, Double)

  • Integer (int): Whole numbers without decimal points (e.g., -3, 0, 42).
  • Float: Numbers including decimal points; fast but prone to rounding errors (e.g., 3.14).
  • Double & Fixed-Point: Highly precise decimals or strict decimal counts (e.g., $12.34).

Booleans & Logic

  • Boolean: A primitive value that is strictly True or False (1 or 0).
  • Logical Operators: Mathematical evaluations that return Boolean outcomes (e.g., 10 > 5 is True).
  • Control Flow: Booleans drive program decisions via conditionals (if/else) and loops.

Casting & Conversion

  • Definition: The programmatic process of converting one data type into another.
  • Strings to Numbers: Using int("45") to perform math on user input.
  • Loss of Data: Converting int(4.9) forcefully truncates the decimal, resulting in 4.
