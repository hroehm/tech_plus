Database Fundamentals

Discover the foundational concepts of databases. Learn how data is structured, stored, and accessed efficiently using Database Management Systems and SQL.

Database vs. Flat File

  • Databases: Highly organized, multi-table digital storage systems that handle concurrent users and massive scalability.
  • Flat Files: Simple spreadsheets with rows and columns, best for small teams but prone to data corruption with multiple users.
  • Creation Process: Involves defining the schema, creating tables, establishing constraints, and importing data.

Storage Types

  • Local Storage: Data saved on physical devices directly connected to your network. Provides full control and speed.
  • Cloud Storage: Data saved on remote servers accessed via the internet. Offers unlimited scalability and automated backups.
  • Data Persistence: The ability of a system to maintain data integrity across sessions and unexpected reboots.

Access Methods

  • Online Access: Interacting with data through an active internet connection. Allows real-time collaboration.
  • Offline Access: Interacting with data stored locally on a device without requiring an internet connection.
  • Data Availability: Ensuring that essential data is accessible and functional exactly when it is needed.

SQL Queries & Records

  • Records & Fields: A record (row) is a collection of fields (columns) containing data values about an entity.
  • Queries: Requests to retrieve, filter, sort, or aggregate data from a database (e.g., using SELECT).
  • Transactions: Using commands like BEGIN TRANSACTION, COMMIT, and ROLLBACK to safely track and apply changes.
