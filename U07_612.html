Integrity Concerns

Explore the "I" in the CIA Triad. Learn how data tampering, replay attacks, and on-path attacks threaten the trustworthiness of data, and how file hashing and digital signatures secure it.

Data Tampering

  • Integrity: Ensuring data is accurate, reliable, and unaltered by unauthorized parties.
  • Intentional Tampering: Malicious actors or disgruntled insiders modifying data.
  • Accidental Tampering: Negligent actions causing data corruption or loss.

Replay Attacks

  • Network Snooping: Capturing data packets as they travel across a network.
  • Reuse of Data: Using previously captured, valid authentication data at a later time.
  • Passive Interception: The attacker does not alter the data, they simply capture and replay it.

On-Path Attacks

  • Adversary-in-the-Middle: An attacker establishing themselves between a client and a server.
  • Active Alteration: Capturing data, modifying it in transit, and sending the forged payload.
  • Rogue Networks: Often executed via fake public Wi-Fi access points.

Ensuring Integrity

  • File Hashing: Using algorithms (MD5, SHA-512) to generate unique file checksums.
  • Digital Signatures: Authenticating the integrity and origin of data using cryptographic keys.
  • Secure Protocols: Utilizing HTTPS and WPA2/WPA3 to encrypt data and prevent interception.
