Objects & Object-Oriented Programming

Master how modern programming environments model real-world items using classes, properties, encapsulation, constructors, and behaviors.

1. Identity & Instantiation

  • Identity: Every object requires a unique name or variable reference in memory.
  • Instantiation: The process of creating a concrete instance from a class blueprint.
  • Constructors: Specialized methods called during instantiation to initialize variables.

2. Classes & Encapsulation

  • Class Blueprint: The template defining default attributes and methods for similar objects.
  • Encapsulation: Bundling data and methods together to promote modularity.
  • Code Reusability: Building once and instantiating countless independent versions.

3. Properties & Attributes

  • State Definition: Characteristics that describe an object's current condition (nouns).
  • Attributes: The actual data values assigned to properties in an instance.
  • Data Types: Strings, integers, booleans, and arrays storing state details.

4. Getters, Setters & Methods

  • Behaviors: Actions and functions that objects can perform (verbs).
  • Getters: Methods designed to retrieve and return property data.
  • Setters: Methods designed to update or modify property state.
