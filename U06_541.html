Data Backups & Recovery

Protect your digital assets. Explore how to safeguard data from loss, corruption, or disaster using physical and cloud storage.

Fundamentals & Planning

  • Prevention & Continuity: Mitigates operational damage from malware, disasters, or user errors.
  • Data Recovery: The critical process of restoring data when original copies are lost.
  • Recovery Plan: Defines what, where, and how often to backup, plus testing methodologies.

File vs. System Backups

  • File Backups: Secures individual documents, photos, or specific directories.
  • System Backups: Captures entire OS images, applications, and settings for total recovery.
  • Backup Methods: Includes Full, Incremental, and Differential backup cycles.

Storage Locations

  • Local Storage: Fast, physical devices like Flash Drives, SD Cards, and External HDDs.
  • Cloud Storage: Off-site, internet-dependent servers (Google Drive, OneDrive, AWS).
  • Trade-offs: Balancing portability, cost, speed, and geographic redundancy.

CLI vs. GUI Management

  • GUI (Graphical): Easy visual drag-and-drop file copying, pasting, and replacing.
  • CLI (Command Line): Powerful text-based syntax for mass file management.
  • Utilities: Utilizing robocopy (Windows) and rsync (Linux) for robust syncing.
