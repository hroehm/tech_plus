The Basics of Computing

Every time we ask a computer to do something, it goes through the same basic cycle. Discover the foundational operations that make all modern technology possible.

Input

  • Definition: User actions directed at the computer; providing data or commands.
  • Direct Input: The user directly interacts with the data, like touching a screen.
  • Indirect Input: Sensors or devices gather and send data, like a mouse or microphone.

Processing

  • Definition: Actions performed to manipulate input data and execute instructions.
  • The Brain: The Central Processing Unit (CPU) acts as the brain of the computer.
  • Translation: Translates user requests into complex binary actions the hardware understands.

Storage

  • Definition: Mechanisms and devices used to save and retain data for later use.
  • Short-Term (Volatile): Random Access Memory (RAM) holds active, running programs.
  • Long-Term (Persistent): Hard Disk Drives (HDD) and Solid State Drives (SSD) save files permanently.

Output

  • Definition: Results generated by processing inputs, delivered back to the user.
  • Visual & Audio: Displays, monitors, projectors, and speakers.
  • Physical: Printers generating hard copies of digital documents.
