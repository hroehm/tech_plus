Storage Devices & Memory Architecture

Master how computers store, retrieve, and process data using volatile memory, non-volatile storage, internal buses, and specialized drives.

SATA & Data Transfer

  • Motherboard Interface: Connects storage drives to motherboard data channels.
  • CPU & RAM Communication: Enables data flow between drives and processor memory.
  • Hot-Swapping: Capability to replace drives without powering down.

Volatile vs. Non-Volatile

  • Volatile Storage: Temporary, high-speed memory that clears on power loss.
  • Non-Volatile Storage: Permanent storage retaining data across reboots.
  • Performance Trade-offs: Speed versus long-term data preservation.

Local Storage: RAM & ROM

  • RAM: Short-term volatile workspace for active CPU instructions.
  • ROM: Permanent firmware and system bootstrap instructions (BIOS/UEFI).
  • Local Physical Access: Direct device attachment without network latency.

Hard Disk Drives (HDDs)

  • Magnetic Platters: Spinning disks storing data magnetically via read/write heads.
  • High Capacity & Value: Maximum storage per dollar spent.
  • Form Factors: 3.5-inch desktop units (7200 RPM) and 2.5-inch laptop units (5400 RPM).

SSDs & NVMe Protocol

  • Flash Memory: Solid-state storage with zero moving parts and high durability.
  • NVMe Protocol: Direct CPU connection via PCIe bus for lightning-fast transfer rates.
  • M.2 Form Factor: Compact stick design minimizing system footprint.

Optical & Flash Drives

  • Optical Media: Laser technology for CDs, DVDs, and Blu-ray archival distribution.
  • External Flash: Portable USB storage chips for mobile data transfer.
  • Legacy & Portability: Specialized roles in modern computing workflows.
